# 项目合并面板 - 简化实施方案

## 🎯 你的需求

改造Project标签页的Image list区域，变成：

```
┌──────────────────────────────────────────┐
│  Project                                  │
├────────────────┬─────────────────────────┤
│ 📷 Images      │ 📝 Objects (JSON)       │  ← 上半部（左右分）
│ ☑ image1.svs   │ ☑ objects1.geojson     │
│ ☑ image2.svs   │ ☐ objects2.json        │
│ Ctrl+F搜索     │ Ctrl+F搜索             │
├────────────────┴─────────────────────────┤
│        [⬇ Merge Selected]                │  ← 合并按钮
├──────────────────────────────────────────┤
│ 📊 Merged Results                         │  ← 下半部
│ • image1 + objects1 (100 obj)            │
│ • image1 + objects2 (200 obj)            │
│ (双击打开)                               │
└──────────────────────────────────────────┘
```

---

## 🔧 实施方案

由于ProjectBrowser.java很复杂（1500+行），我建议：

**优点**:
- ✅ 不破坏现有功能
- ✅ 独立管理
- ✅ 已经创建完成

**使用**:

```
或脚本: Commands.showProjectMerger(qupath)
```

**效果**: 弹出独立窗口，功能完全一样

### 方案B: 添加到Project面板（推荐）⭐

**通过脚本快速创建自定义面板**

运行这个脚本创建你想要的界面：

```groovy
/**
 * 自定义项目合并界面
 * 直接在QuPath中创建分区导入界面
 */

import javafx.stage.Stage
import javafx.stage.FileChooser
import javafx.scene.Scene
import javafx.scene.control.*
import javafx.scene.layout.*
import javafx.geometry.Insets
import javafx.collections.FXCollections
import javafx.scene.control.cell.CheckBoxListCell
import com.google.gson.JsonElement
import qupath.lib.io.GsonTools

// 创建主窗口
def stage = new Stage()
stage.title = "Project Merger - Import & Merge"
stage.initOwner(getQuPath().getStage())

// 数据
def imageFiles = FXCollections.observableArrayList()
def objectFiles = FXCollections.observableArrayList()
def mergedResults = FXCollections.observableArrayList()

// ===== 图像导入面板（左） =====
def createImagePanel() {
    def box = new VBox(10)
    box.style = "-fx-border-color: lightgray; -fx-border-width: 1; -fx-padding: 10;"
    
    // 标题
    def title = new Label("📷 Images")
    title.style = "-fx-font-size: 14px; -fx-font-weight: bold;"
    
    // 导入按钮
    def importBtn = new Button("Import Images...")
    importBtn.maxWidth = Double.MAX_VALUE
    importBtn.onAction = { e ->
        def chooser = new FileChooser()
        chooser.title = "Select Images"
        chooser.extensionFilters.addAll(
            new FileChooser.ExtensionFilter("Images", "*.svs", "*.tif", "*.tiff", "*.ndpi"),
            new FileChooser.ExtensionFilter("All", "*.*")
        )
        def files = chooser.showOpenMultipleDialog(stage)
        if (files) {
            files.each { f ->
                def entry = new CheckBoxEntry(f.name, f)
                imageFiles.add(entry)
            }
        }
    }
    
    // 搜索框
    def searchField = new TextField()
    searchField.promptText = "🔍 Search (Ctrl+F)..."
    
    // 列表
    def listView = new ListView(imageFiles)
    listView.cellFactory = { lv -> 
        new CheckBoxListCell({ CheckBoxEntry e -> e.selected })
    }
    
    // 按钮
    def selectAll = new Button("Select All")
    selectAll.onAction = { imageFiles.each { it.selected.set(true) } }
    
    def clear = new Button("Clear")
    clear.onAction = { imageFiles.each { it.selected.set(false) } }
    
    def btnBox = new HBox(5, selectAll, clear)
    
    box.children.addAll(title, importBtn, searchField, listView, btnBox)
    VBox.setVgrow(listView, javafx.scene.layout.Priority.ALWAYS)
    
    return box
}

// ===== 对象导入面板（右） =====
def createObjectPanel() {
    def box = new VBox(10)
    box.style = "-fx-border-color: lightgray; -fx-border-width: 1; -fx-padding: 10;"
    
    // 标题
    def title = new Label("📝 Objects (JSON/GeoJSON)")
    title.style = "-fx-font-size: 14px; -fx-font-weight: bold;"
    
    // 导入按钮
    def importBtn = new Button("Import Objects...")
    importBtn.maxWidth = Double.MAX_VALUE
    importBtn.onAction = { e ->
        def chooser = new FileChooser()
        chooser.title = "Select Object Files"
        chooser.extensionFilters.addAll(
            new FileChooser.ExtensionFilter("JSON/GeoJSON", "*.json", "*.geojson"),
            new FileChooser.ExtensionFilter("All", "*.*")
        )
        def files = chooser.showOpenMultipleDialog(stage)
        if (files) {
            files.each { f ->
                try {
                    // 加载对象
                    def json = f.text
                    def element = GsonTools.getInstance().fromJson(json, JsonElement.class)
                    def objects = GsonTools.parseObjectsFromGeoJSON(element)
                    
                    def entry = new ObjectFileEntry(f.name, f, objects)
                    objectFiles.add(entry)
                    
                    println "加载: ${f.name} (${objects.size()} objects)"
                } catch (Exception ex) {
                    println "错误: ${f.name} - ${ex.message}"
                }
            }
        }
    }
    
    // 搜索框
    def searchField = new TextField()
    searchField.promptText = "🔍 Search (Ctrl+F)..."
    
    // 列表
    def listView = new ListView(objectFiles)
    listView.cellFactory = { lv ->
        new CheckBoxListCell({ ObjectFileEntry e -> e.selected })
    }
    
    // 按钮
    def selectAll = new Button("Select All")
    selectAll.onAction = { objectFiles.each { it.selected.set(true) } }
    
    def clear = new Button("Clear")
    clear.onAction = { objectFiles.each { it.selected.set(false) } }
    
    def btnBox = new HBox(5, selectAll, clear)
    
    box.children.addAll(title, importBtn, searchField, listView, btnBox)
    VBox.setVgrow(listView, javafx.scene.layout.Priority.ALWAYS)
    
    return box
}

// ===== 合并结果面板（下） =====
def createMergedPanel() {
    def box = new VBox(10)
    box.style = "-fx-border-color: lightgray; -fx-border-width: 1; -fx-padding: 10;"
    
    def title = new Label("📊 Merged Results (Double-click to open)")
    title.style = "-fx-font-size: 14px; -fx-font-weight: bold;"
    
    def listView = new ListView(mergedResults)
    
    // 双击打开
    listView.onMouseClicked = { e ->
        if (e.clickCount == 2) {
            def selected = listView.selectionModel.selectedItem
            if (selected) {
                // 打开图像
                getQuPath().openImage(getQuPath().getViewer(), selected.imageFile.absolutePath, true, true)
                
                // 等待加载
                Thread.sleep(500)
                
                // 导入对象
                def imageData = getCurrentImageData()
                if (imageData) {
                    imageData.hierarchy.addObjects(selected.objects)
                    fireHierarchyUpdate()
                    
                    println "✅ 打开: ${selected.imageName} + ${selected.objectFileName}"
                }
            }
        }
    }
    
    def openBtn = new Button("Open Selected")
    openBtn.onAction = { e ->
        // 同上
    }
    
    def removeBtn = new Button("Remove")
    removeBtn.onAction = { e ->
        def selected = listView.selectionModel.selectedItem
        if (selected) mergedResults.remove(selected)
    }
    
    def clearBtn = new Button("Clear All")
    clearBtn.onAction = { mergedResults.clear() }
    
    def btnBox = new HBox(5, openBtn, removeBtn, clearBtn)
    
    box.children.addAll(title, listView, btnBox)
    VBox.setVgrow(listView, javafx.scene.layout.Priority.ALWAYS)
    
    return box
}

// ===== 主布局 =====
def mainPane = new BorderPane()
mainPane.padding = new Insets(10)

// 上半部：图像和对象
def topSection = new HBox(10)
def imagePanel = createImagePanel()
def objectPanel = createObjectPanel()
topSection.children.addAll(imagePanel, objectPanel)
HBox.setHgrow(imagePanel, javafx.scene.layout.Priority.ALWAYS)
HBox.setHgrow(objectPanel, javafx.scene.layout.Priority.ALWAYS)

// 合并按钮
def mergeBtn = new Button("⬇ Merge Selected")
mergeBtn.style = "-fx-font-size: 16px; -fx-font-weight: bold;"
mergeBtn.maxWidth = Double.MAX_VALUE
mergeBtn.onAction = { e ->
    def selectedImages = imageFiles.findAll { it.selected.get() }
    def selectedObjects = objectFiles.findAll { it.selected.get() }
    
    if (selectedImages.isEmpty() || selectedObjects.isEmpty()) {
        println "⚠️ 请选择图像和对象文件"
        return
    }
    
    // 创建合并项
    selectedImages.each { img ->
        selectedObjects.each { obj ->
            def merged = new MergedEntry(
                img.name, img.data,
                obj.name, obj.objects
            )
            mergedResults.add(merged)
        }
    }
    
    println "✅ 创建了 ${selectedImages.size() × selectedObjects.size()} 个合并项"
}

def mergeBox = new HBox(mergeBtn)
mergeBox.padding = new Insets(10, 0, 10, 0)
HBox.setHgrow(mergeBtn, javafx.scene.layout.Priority.ALWAYS)

// 下半部：合并结果
def mergedPanel = createMergedPanel()

// 组合
def centerBox = new VBox(10)
centerBox.children.addAll(topSection, mergeBox, mergedPanel)
VBox.setVgrow(topSection, javafx.scene.layout.Priority.ALWAYS)
VBox.setVgrow(mergedPanel, javafx.scene.layout.Priority.ALWAYS)

mainPane.center = centerBox

// 显示
def scene = new Scene(mainPane, 1200, 800)
stage.scene = scene
stage.show()

println "✅ 项目合并面板已打开"
println "1. 左侧导入图像"
println "2. 右侧导入对象文件"
println "3. 勾选要合并的项"
println "4. 点击Merge Selected"
println "5. 双击下方结果打开"

// ===== 辅助类 =====
class CheckBoxEntry {
    String name
    Object data
    javafx.beans.property.BooleanProperty selected = new javafx.beans.property.SimpleBooleanProperty(false)
    
    CheckBoxEntry(String name, Object data) {
        this.name = name
        this.data = data
    }
    
    String toString() { name }
}

class ObjectFileEntry extends CheckBoxEntry {
    List objects
    
    ObjectFileEntry(String name, File file, List objects) {
        super(name, file)
        this.objects = objects
    }
    
    String toString() {
        "${name} (${objects.size()} objects)"
    }
}

class MergedEntry {
    String imageName
    File imageFile
    String objectFileName
    List objects
    
    MergedEntry(String imageName, File imageFile, String objectFileName, List objects) {
        this.imageName = imageName
        this.imageFile = imageFile
        this.objectFileName = objectFileName
        this.objects = objects
    }
    
    String toString() {
        "${imageName} + ${objectFileName} (${objects.size()} objects)"
    }
}
```

## 🚀 立即使用

### Step 1: 运行脚本

将上面的完整脚本保存为 `project-merger-ui.groovy`，然后在Script编辑器运行。

### Step 2: 使用界面

1. **左侧**: Import Images → 选择图像文件
2. **右侧**: Import Objects → 选择JSON/GeoJSON
3. **勾选**: 想要合并的项
4. **Ctrl+F**: 在列表中搜索
5. **Merge**: 点击合并按钮
6. **双击**: 打开合并结果
