# 树形通道面板使用说明

## 🎯 功能说明

新增了一个**树形结构的通道控制面板**，提供更直观的RGB通道管理：

### 核心功能
- 🌳 **树形展示**：RGB图像显示为可展开/折叠的树形节点
- ▶️ **展开/折叠**：点击左侧箭头展开查看R、G、B子通道
- ☑️ **批量选择**：点击父节点复选框一次性选中/取消所有子通道
- 🎨 **颜色调节**：双击颜色方块修改通道颜色（保留原功能）
- 🔄 **实时同步**：与主视图的通道控制完全同步

## 📍 如何使用

### 步骤1：创建多通道叠加
1. 打开QuPath并加载项目
2. 菜单：**View → Multi-channel overlay...**
3. 选择要叠加的图像
4. **勾选** "Expand RGB images to separate R, G, B channels"
5. 点击 "Create Overlay"

### 步骤2：打开树形通道面板
1. 菜单：**View → Hierarchical channel view**
2. 会弹出一个新窗口显示树形通道列表

### 步骤3：使用树形面板

#### 界面布局
```
┌─────────────────────────────────────┐
│ Channels (Hierarchical View)        │
├─────────────────────────────────────┤
│ ▶ ☐ light.svs          [■]         │  ← RGB父节点（折叠状态）
│                                      │
│ ▼ ☑ qp1_480_all.svs    [■]         │  ← RGB父节点（展开状态）
│    ☑ Red               [🔴]         │  ← R子通道
│    ☑ Green             [🟢]         │  ← G子通道
│    ☐ Blue              [🔵]         │  ← B子通道
│                                      │
│ ☑ image3.tif           [■]         │  ← 灰度图像（无子通道）
└─────────────────────────────────────┘
```

#### 操作说明

**1. 展开/折叠RGB通道**
- 点击 ▶ 箭头 → 变成 ▼，展开显示R、G、B
- 再次点击 ▼ 箭头 → 变成 ▶，折叠隐藏子通道

**2. 选择/取消选择通道**
- 勾选父节点复选框 → 同时选中所有R、G、B通道
- 取消勾选父节点 → 同时取消所有R、G、B通道
- 单独勾选子通道 → 只显示特定颜色（如只看红色）

**3. 调整通道颜色**
- 双击颜色方块 [■] → 打开颜色选择器
- 选择新颜色 → 实时更新显示效果

**4. 半选中状态**
- 如果只选中部分子通道（如R和G，不选B）
- 父节点显示为 ☑（半选状态）
- 表示该RGB图像只部分显示

## 🎮 使用场景

### 场景1：查看完整RGB图像
```
✅ 父节点勾选
   ✅ Red 通道
   ✅ Green 通道
   ✅ Blue 通道
```
**效果**：显示完整的彩色图像

### 场景2：只查看红色成分
```
▼ 父节点展开
   ✅ Red 通道
   ☐ Green 通道
   ☐ Blue 通道
```
**效果**：只显示红色通道，便于分析红色染色

### 场景3：对比两个颜色通道
```
▼ 父节点展开
   ✅ Red 通道
   ☐ Green 通道
   ✅ Blue 通道
```
**效果**：显示红+蓝的叠加，绿色隐藏

### 场景4：多图像同时控制
```
▼ image1.svs (Red, Green, Blue - 全选)
▼ image2.svs (Red only - 只看红色)
▶ image3.svs (折叠 - 快速开关)
```
**效果**：灵活组合不同图像的不同通道

## 🆚 对比原有功能

| 特性 | 原 Brightness & contrast | 新 Hierarchical view |
|------|-------------------------|----------------------|
| RGB通道 | 平铺显示9个通道 | 树形分组，可折叠 |
| 批量选择 | 需要逐个勾选 | 点击父节点一次搞定 |
| 界面简洁度 | ⚠️ 9个通道占空间 | ✅ 可折叠，节省空间 |
| 颜色调节 | ✅ 支持 | ✅ 支持（双击） |
| 亮度对比度 | ✅ 有滑块 | ❌ 暂无（使用原面板） |

**建议**：
- **通道选择** → 使用新的树形面板（更方便）
- **亮度调节** → 使用原有的 Brightness & contrast 面板

## 💡 实用技巧

### 技巧1：快速切换通道组合
1. 折叠所有不需要的RGB图像（点击▼变▶）
2. 展开需要精细控制的图像
3. 通过展开/折叠快速切换显示内容

### 技巧2：对比不同染色
假设有3个不同波长的图像：
```
▼ 480nm.svs
   ✅ Green  ← 主要绿色成分
   
▼ 570nm.svs
   ✅ Red    ← 主要红色成分
   
▼ 660nm.svs
   ✅ Blue   ← 主要蓝色成分
```
点击父节点可以快速开关整个波长的图像

### 技巧3：简化界面
- 不关心的通道 → 折叠起来
- 正在分析的通道 → 展开详细控制
- 界面始终保持整洁
