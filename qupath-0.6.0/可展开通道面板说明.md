# 可展开通道面板 - 使用说明

## 🎯 新功能说明

创建了一个**可展开/折叠的通道控制面板**，解决了RGB图像通道显示混乱的问题！

### 核心特性
- 📁 **默认折叠**：RGB图像默认显示为一行，例如 `qp1_480_all.svs`
- ▶️ **展开按钮**：点击左侧▶箭头，展开显示 Red、Green、Blue 子通道
- ☑️ **智能勾选**：
  - **不展开，直接勾选父节点** → 选中所有R+G+B通道，显示完整彩色
  - **展开后勾选子通道** → 单独控制每个颜色通道
- 🎨 **颜色调节**：双击颜色方块可修改通道颜色（待实现）
- 🔄 **实时同步**：与主视图完全同步

## 🚀 使用步骤

### 步骤1：创建多通道叠加
1. 启动QuPath并打开项目
2. 菜单：**View → Multi-channel overlay...**
3. 选择要叠加的图像
4. **勾选** "Expand RGB images to separate R, G, B channels"
   （必须勾选，这样才能展开/折叠）
5. 点击 "Create Overlay"

### 步骤2：打开可展开通道面板
1. 菜单：**View → Hierarchical channel view**
2. 会弹出一个新窗口，显示可展开的通道列表

### 步骤3：使用面板

#### 操作A：查看完整RGB图像（不展开）
1. **不点击箭头**
2. 直接勾选 `☑ qp1_480_all.svs`
3. 结果：显示完整的彩色图像（R+G+B全选）

#### 操作B：单独控制某个颜色通道
1. 点击 ▶ 箭头，展开为 ▼
2. 显示3个子通道：Red、Green、Blue
3. 勾选需要的通道，例如只勾选 Red
4. 结果：只显示红色通道

#### 操作C：折叠不需要的通道
1. 点击 ▼ 箭头，折叠为 ▶
2. 子通道隐藏，界面更简洁
3. 但通道的选中状态保持不变

## 💡 使用场景

### 场景1：快速查看所有图像（默认）
```
▶ ☑ light.svs
▶ ☑ qp1_480_all.svs
▶ ☑ qp1_520_yuan.svs
```
**效果**：3个图像全部显示，每个都是完整RGB，界面只有3行！

### 场景2：精细控制某个图像
```
▶ ☑ light.svs                      ← 完整RGB
▼ ☐ qp1_480_all.svs                ← 展开控制
   ☑ Red                          ← 只看红色
   ☐ Green
   ☐ Blue
▶ ☑ qp1_520_yuan.svs               ← 完整RGB
```
**效果**：light和qp1_520显示完整彩色，qp1_480只显示红色通道

### 场景3：对比两个通道
```
▼ ☐ qp1_480_all.svs
   ☑ Red                          ← 叠加显示
   ☐ Green
   ☑ Blue                         ← 叠加显示
```
**效果**：显示红+蓝的叠加效果，绿色通道隐藏
