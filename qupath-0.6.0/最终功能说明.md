## 🚀 使用步骤

### 1. 创建多通道叠加
```
View → Multi-channel overlay...
选择图像（light.svs, qp1_480_all.svs, 等等）
☑ 勾选 "Expand RGB images to separate R, G, B channels"
点击 "Create Overlay"
```

### 2. 打开Brightness & contrast
```
View → Brightness & contrast
或者直接按快捷键
```

### 3. 看到集成的通道视图
```
✅ 顶部会出现 "Hierarchical Channel View"
✅ 默认是展开状态，显示所有图像
✅ 每个图像都是折叠的（显示为 ▶）
```

## 💡 操作指南

### 操作A：快速选择/取消整个RGB图像
```
▶ ☑ qp1_480_all.svs  [■]  ← 直接点击这个复选框
```
**效果**：一次性选中或取消该图像的所有R、G、B通道

### 操作B：单独控制某个颜色通道
```
点击 ▶，变成 ▼
▼ ☐ qp1_480_all.svs  [■]
   ☑ Red             [🔴]  ← 只勾选红色
   ☐ Green           [🟢]
   ☐ Blue            [🔵]
```
**效果**：只显示红色通道

### 操作C：隐藏整个可展开视图
```
点击 ▼ Hierarchical Channel View
变成 ▶ Hierarchical Channel View
```
**效果**：节省空间，使用传统的通道表格

### 操作D：同时使用两个视图
```
上面：快速开关整个RGB图像
下面：精细调整某个通道的颜色、亮度
底部：调整滑块
```

## 📝 注意事项

1. **必须勾选 Expand RGB 选项**
   - 创建overlay时勾选
   - 否则无法展开/折叠

2. **两个视图可以同时使用**
   - 上面快速操作
   - 下面详细调整

3. **可以完全隐藏上面的视图**
   - 点击 ▶ 折叠 "Hierarchical Channel View"
   - 就像没有添加这个功能一样

4. **第一次打开可能需要等待**
   - 加载图像数据需要时间
   - 视图会自动出现

## 🔧 快捷键

- 打开 Brightness & contrast: 查看菜单中的快捷键
- 展开/折叠视图: 点击 ▼/▶ 图标
- 选择通道: 点击复选框
- 调整颜色: 双击颜色方块（待实现）
