# 多通道叠加修复说明

## 修复的问题

### 问题1：无法同时选择多个通道
**原因**：通道选择的时机太早，在UI完全更新之前就尝试设置通道状态。

**修复方案**：
- 在`MultiChannelOverlayCommand.java`中使用双层`Platform.runLater()`
- 第一层：设置ImageData
- 第二层：等待UI完全更新后，再配置通道选择状态
- 添加`qupath.getViewer().repaint()`强制更新显示

### 问题2：无法调节通道颜色
**原因**：创建ImageChannel时没有指定颜色，导致QuPath无法为通道提供颜色调节功能。

**修复方案**：
- 在`MultiChannelOverlayServer.java`中修改通道创建逻辑
- 使用`ImageChannel.getDefaultChannelColor(i)`为每个通道分配默认颜色
- 颜色按照QuPath的标准配色方案分配（品红、红、绿、蓝等）

## 修改的文件

### 1. MultiChannelOverlayCommand.java
```java
// 修改前：
Platform.runLater(() -> {
    ImageData<BufferedImage> imageData = new ImageData<>(overlayServer);
    qupath.getViewer().setImageData(imageData);
    
    for (var channel : availableChannels) {
        display.setChannelSelected(channel, true);
    }
});

// 修改后：
Platform.runLater(() -> {
    ImageData<BufferedImage> imageData = new ImageData<>(overlayServer);
    qupath.getViewer().setImageData(imageData);
    
    // 等待UI更新
    Platform.runLater(() -> {
        for (var channel : availableChannels) {
            display.setChannelSelected(channel, true);
        }
        qupath.getViewer().repaint();
    });
});
```

### 2. MultiChannelOverlayServer.java
```java
// 修改前：
for (int i = 0; i < servers.size(); i++) {
    channels.add(ImageChannel.getInstance(channelNames.get(i), i));
}

// 修改后：
for (int i = 0; i < servers.size(); i++) {
    Integer channelColor = ImageChannel.getDefaultChannelColor(i);
    channels.add(ImageChannel.getInstance(channelNames.get(i), channelColor));
}
```

## 功能说明

现在您可以：
1. **同时显示多个通道**：勾选多个通道的复选框
2. **调节通道颜色**：点击通道颜色方块，选择自定义颜色
3. **调节亮度对比度**：使用滑块调整每个通道的显示参数
4. **查看叠加效果**：多个通道会以不同颜色叠加显示
